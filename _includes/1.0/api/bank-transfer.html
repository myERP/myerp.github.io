Bank Transfers

{% highlight bash %}Endpoint: {{ site.api.base_url }}{{ site.api.v1}}{{ site.resource.bank_transfers.url}}{% endhighlight %}

A Bank Transfer records a movement of money between two bank accounts.
You can specify both the source (from) and destination (to) accounts, or only one of the two — for example, if you are only the receiving party and do not manage the sending account in OneUp, or vice versa.
Multi-currency transfers are supported: if from and to use different currencies, exchange rates are computed automatically.

JSON Format

Bank Transfers are represented as JSON objects which have the following keys:

{% include table-header.html %}
id {{ site.format.type.integer }} no yes Automatically assigned when creating a Bank Transfer.
user_code {{ site.format.type.string }} no yes The number automatically assigned to this Bank Transfer (e.g. BTRF-007).
date {{ site.format.type.date }} no no The date of the transfer.
Format: {{ site.format.date }}
Default: date of the day.
notes {{ site.format.type.string }} no no A description of the transfer purpose. 255 characters max.
from {{ site.format.type.object }} no no The debit side of the transfer. See Transfer Direction table below. Can be omitted if you are only the receiving party.
to {{ site.format.type.object }} no no The credit side of the transfer. See Transfer Direction table below. Can be omitted if you are only the sending party.
budget_category {{ site.format.type.object }} no no The budget category associated with this transfer. Contains id and name.

Transfer Direction (from / to)

Both from and to share the same structure:

{% include table-header.html %}
bank_account {{ site.format.type.object }} no no The bank account on this side of the transfer. Contains id and name.
from.bank_account and to.bank_account must be different when both are provided.
amount {{ site.format.type.double }} yes no The transfer amount on this side. Must be greater than 0.
currency_iso_code {{ site.format.type.string }} no yes The ISO code of the currency (ISO 4217). Derived from the bank account's currency.
