Sales Receipts

{% highlight bash %}Endpoint: {{ site.api.base_url }}{{ site.api.v1}}{{ site.resource.sales_receipts.url}}{% endhighlight %}

A Sales Receipt represents a categorized income collected directly from a customer, vendor, employee, or any other payee — without going through an invoice.
It is made up of one or more Category Lines that split the total amount across accounting accounts and budget categories.
Setting a payment_date (or a bank_account) marks the document as deposited. Clearing them reverts it to unpaid.

A POST /v1/sales_receipts/search endpoint is also available for advanced filtering.

JSON Format

Sales Receipts are represented as JSON objects which have the following keys:

{% include table-header.html %}
id {{ site.format.type.integer }} no yes Automatically assigned when creating a Sales Receipt.
user_code {{ site.format.type.string }} no yes The number automatically assigned to this Sales Receipt (e.g. REC-012). 64 characters max.
status {{ site.format.type.string }} no yes Payment status of the document. deposited when a payment_date is set, not_deposited otherwise.
type {{ site.format.type.string }} no no Whether the document has a single line or multiple lines. Values: simple, multi-line.
payee_type {{ site.format.type.string }} no no Type of the payee. Values: CUSTOMER, VENDOR, EMPLOYEE, BANK_ACCOUNT, NO_PAYEE.
payee {{ site.format.type.snippet }} no no The payee of this Sales Receipt. Must belong to the type specified by payee_type.
date {{ site.format.type.date }} no no The date of the Sales Receipt.
Format: {{ site.format.date }}
Default: date of the day.
due_date {{ site.format.type.date }} no no The due date for payment (for unpaid documents).
Format: {{ site.format.date }}
payment_date {{ site.format.type.date }} no no The date the payment was deposited to the bank account. Setting this field marks the document as deposited.
Format: {{ site.format.date }}
payment_method {{ site.format.type.string }} no no The payment method used (e.g. CHECK, WIRE_TRANSFER, CREDIT_CARD).
bank_account {{ site.format.type.object }} no no The bank account the amount was deposited into. Contains id and name.
transaction_id {{ site.format.type.string }} no no A free reference label (e.g. a bank statement reference). 255 characters max.
notes {{ site.format.type.string }} no no Free notes attached to this Sales Receipt. 255 characters max.
currency_iso_code {{ site.format.type.string }} no no The ISO code of the currency (ISO 4217).
Default: your company's currency.
total_amount {{ site.format.type.double }} no yes Total amount including taxes. Computed from the sum of all category lines.
assigned_to {{ site.format.type.object }} no no The employee assigned to this document. Contains id, first_name, last_name.
Default: the authenticated user.
project {{ site.format.type.object }} no no The project this Sales Receipt is linked to, if any. Contains id and name.
locked {{ site.format.type.boolean }} no yes Indicates that the document can no longer be edited nor deleted (e.g. due to a locked accounting period or VAT reconciliation).
bank_reconciled {{ site.format.type.boolean }} no yes Indicates whether this Sales Receipt has been matched against a bank entry.
lines {{ site.format.type.category_line }} no no The category lines of this Sales Receipt. Adding, updating or removing a line updates total_amount accordingly.
metadata {{ site.format.type.object }} no yes Extended status information. Contains document_status and payment_status keys.
