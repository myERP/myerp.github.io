Payment Terms

{% highlight bash %}Endpoint: {{ site.api.base_url }}{{ site.api.v1}}{{ site.resource.payment_terms.url}}{% endhighlight %}

This API doesn't handle DELETE requests. Payment Terms are referred to by Customers, Vendors and documents, so they cannot be removed through the API.

JSON Format

Payment Terms are represented as JSON objects which have the following keys:

{% include table-header.html %}
id {{ site.format.type.integer }} no yes Automatically assigned
name {{ site.format.type.string }} yes on creation no The Payment Term Name. 64 characters max.
lines {{ site.format.type.payment_term_line }} yes on creation no An array containing the installments of the Payment Term.
A Payment Term needs at least one installment, and the percentages of its installments must add up to 100.

Updating the installments

On a PUT request, lines is optional and behaves as follows:

  • Leave lines out and the schedule is left untouched, so you can rename a Payment Term on its own.
  • Send lines and it becomes the whole schedule. An installment sent with its id is updated, one sent without an id is created, and any installment of the Payment Term missing from the array is removed.

An id sent in lines has to be the id of an installment of that very Payment Term.
