JSON Format

Vendor credit memos are represented as JSON objects which have the following keys:

{% include table-header.html %}
id {{ site.format.type.integer }} no yes Automatically assigned.
locked {{ site.format.type.boolean }} no no Indicates that the document can no longer be edited nor deleted.
sent {{ site.format.type.boolean }} no no Has the document been finalized or sent to the Vendor.
sent_at {{ site.format.type.date }} no no The date the document has been finalized or sent to the Vendor.
Format: {{ site.format.date }}
vendor {{ site.format.type.snippet }} no no The Snippet of the memo Vendor. None when the memo is for a customer or an employee (see payee_type).
Where :
- id = vendor.id
- name = vendor.full_name
- user_code = vendor.user_code
payee_type {{ site.format.type.string }} no no Who the memo is for, as for an Expense, given by payee. Values: VENDOR, CUSTOMER, EMPLOYEE, NO_PAYEE.
Always returned: VENDOR for a memo for a vendor, NO_PAYEE for a memo without any payee.
Sent without payee: VENDOR has the memo for its vendor, NO_PAYEE leaves it without any payee. Left out, the memo keeps its payee, or is for the vendor sent.
The payee can change from or to a customer or an employee until the memo is refunded. Otherwise the change is refused (NOT_EDITABLE).
payee {{ site.format.type.snippet }} no no Who the memo is for: a Vendor, a Customer or an Employee, as payee_type says. Always returned, except with NO_PAYEE.
- VENDOR: the vendor of the memo. It is the vendor itself, unless the memo is for another vendor, its creditor, whose account it is then posted on. A creditor is set at creation only. A memo sent without a vendor takes this one as its vendor.
- CUSTOMER: the memo then has no vendor, and it is posted on the customer's account, in the sales journal.
- EMPLOYEE: the memo then has no vendor, and it is posted on the employee's account.
Sent without payee_type, it is a vendor.
Where :
- id = the id of the vendor, customer or employee
- name = their full name
- user_code = their user code
paid {{ site.format.type.double }} no yes Total of the payments made on that credit memo.
unpaid {{ site.format.type.double }} no yes Remaining amount to be paid.
user_code {{ site.format.type.string }} no no The number assigned to this bill (i.e. SCN-001). If you don't specify a a credit memo number, it will be automatically generated. 64 characters max.
ref_number {{ site.format.type.string }} no no The vendor's own reference number for this credit memo. 64 characters max.
This field can be cleared with a blank or empty string only, not a null value
date {{ site.format.type.date }} no no The date that will be printed.
Format: {{ site.format.date }}
Default: date of the day.
currency_iso_code {{ site.format.type.string }} no no The ISO Code of one of your Currencies
by default, the domain currency will be selected. 4 characters max.
employee_id {{ site.format.type.integer }} no no Id of the Employee assigned to that bill.
Default: the authenticated user.
private_note {{ site.format.type.string }} no no A private note that won't be printed.
subtotal {{ site.format.type.double }} no yes Total before taxes and reduce. Based on the content of the order lines.
reduce_amount {{ site.format.type.double }} no yes Amount of the reduce, based on the subtotal and reduce rate.
tax_amount {{ site.format.type.double }} no yes Overall tax amount. Includes all taxes, discounts and reduce.
total {{ site.format.type.double }} no yes The final total due by the vendor. All include (taxes, discounts, reduce).
