Vendor Credit Memo Payments

{% highlight bash %}Endpoint: {{ site.api.base_url }}{{ site.api.v1}}{{ site.resource.vendor_credit_memo_payments.url}}{% endhighlight %}

Vendor Credit Memo Payment creation is restrained to Vendor Credit Memo payments into the API. You have to provide a vendor_credit_memo_id while performing a POST request.
That new payment will be applied on the first open installment of that vendor credit memo. If all installments are paid, an error message will be returned and the payment won't be created.
Also, that new payment currency will be determined by the vendor credit memo's one.
bank_id is mandatory when creating a vendor credit memo payment.

Unlike creation, GET requests are not restrained to vendor credit memo payments only and return any kind of vendor credit memo payments.

JSON Format

Vendor Credit Memo Payments are represented as JSON objects which have the following keys:

{% include table-header.html %}
id {{ site.format.type.integer }} no yes Automatically assigned when creating a Vendor Credit Memo Payment.
user_code {{ site.format.type.string }} no yes The number that was automatically assigned to this vendor credit memo payment (i.e. SCNPAY-002).
vendor_credit_memo_id {{ site.format.type.integer }} yes yes Id of the Vendor Credit Memo that payment is about.
date {{ site.format.type.date }} no yes The date the payment has occurred.
Format: {{ site.format.date }}
Default: date of the day.
amount {{ site.format.type.double }} no yes Amount of the payment.
Default: remaining unpaid amount of the first open installment.
Should not be 0.00.
currency_iso_code {{ site.format.type.string }} no yes The ISO code of that payment currency (ISO 4217).
Derived from the vendor credit memo's currency.
payment_method_id {{ site.format.type.integer }} no yes Id of the Payment method.
Default: the one of the installment that payment has been applied.
bank_reference {{ site.format.type.string }} no yes A bank reference label that can freely be assigned. Could be a bank statement reference, a transfer ID, etc...
bank_id {{ site.format.type.integer }} yes yes Id of the bank account that payment was made from.
That bank account currency must match the vendor credit memo's currency.
